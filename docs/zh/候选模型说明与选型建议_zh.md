## 1. 先明确我们要解决什么问题

目前草案是：根据温度、压力、湿度等九项环境与过程测量，估计同一时刻的 **CO 浓度**。

- 这是回归任务，输出是连续数值，而不是类别。
- CO 或 NOx 都可以作为目标，最终由小组确认；课程禁止把 TEY 作为目标。
- 当前建议不使用另一污染物 NOx 作为输入，避免部署时仍依赖另一个污染物分析仪。
- 这是当期浓度估计，不是未来一小时预测。

此前实际数据检查发现，过程变量之间有很强的相关性，CO 存在近零值和长尾。因此模型比较应关注：

1. 能否学习非线性和变量之间的共同作用。
2. 是否只记住训练数据，而不能适应后续时间段。
3. 平均误差、较大误差及误差容限覆盖率。
4. 训练、预测和存储成本。

## 2. 整体比较

下表是选型指导，不是实际性能排名。

| 模型 | 通俗理解 | 主要优势 | 主要不足 |
|---|---|---|---|
| 线性回归 | 给每个传感器一个权重，再加起来 | 简单、快、方便解释 | 难表达复杂关系 |
| Ridge 回归 | 给线性回归加上“别把权重调得太夸张”的限制 | 适合输入高度相关的情况 | 本身仍是线性关系 |
| 二次特征＋Ridge | 增加平方项和变量组合，再做受约束的回归 | 能学习较简单的弯曲和交互关系 | 复杂关系仍可能学不够，外推有风险 |
| 单棵决策树 | 按条件一步步判断工况 | 直观，容易展示 | 容易记住训练数据、不够稳定 |
| 随机森林 | 多棵不同的树分别估计，再取平均 | 能学习非线性，通常较稳健 | 模型可能较大，难解释完整预测过程 |
| Extra Trees | 让树的切分方式更加随机，再取平均 | 提供另一种速度与泛化权衡 | 可能错过重要的精细规律 |
| 直方图梯度提升 | 后面的树逐步修正前面预测的不足 | 能表达复杂关系，适合比较表格数据模型 | 参数相互影响，讲解难度更高 |
| SVR | 找一个允许小误差、同时不过分弯曲的预测曲面 | 能学习平滑的非线性关系 | 需要标准化，数据多时调参较慢 |

## 3. 线性回归：最简单的加权公式

### 怎么预测

可以把它想成：

```text
预测 CO = 常数 + 温度权重 × 温度 + 压力权重 × 压力 + ……
```

模型学习每项测量对应的权重，再计算预测值。

例如，它可以描述“其他输入保持相同时，温度增加一个单位，预测 CO 改变多少”。
这表示数据中的关联，不能直接解释为物理因果关系。

### 优点

- 训练和预测很快，适合作为比较起点。
- 参数少，整个流程容易理解。
- 如果复杂模型只改善一点点，却增加很多计算成本，简单模型仍可能有部署价值。

### 不足

- 默认各输入的影响是线性的。
- 一个输入的作用，不会因为另一个输入变化而自动改变。
- 高度相关的输入会使单个系数不稳定：不同的权重组合可能产生相似预测。

真实工况可能是“温度较低时，压力影响明显；温度较高时，压力影响较弱”。
普通线性回归不能直接表达这种交互，需要增加相应特征。

参考：[scikit-learn 线性模型说明](https://scikit-learn.org/stable/modules/linear_model.html)。

### 在本项目中的位置

线性回归是比较参考。当前草案协议下，已经实际运行的五折平均验证 MAE 为 **0.9073 mg/m³**。
后面的候选应在相同协议下重新运行后与它比较。

## 4. Ridge 和二次 Ridge：给简单公式增加约束与表达能力

### 4.1 普通 Ridge 做了什么

如果两个压力传感器提供非常相似的信息，普通线性回归可能给一个很大的正权重，
给另一个很大的负权重，让两者相互抵消。

Ridge 增加一种约束：既要预测准确，也尽量避免使用特别大的权重。

控制约束强度的参数是 `alpha`：

- 太小：约束弱，接近普通线性回归。
- 太大：约束强，可能把有用规律也压得太平。
- 合适程度：通过开发集交叉验证选择。

**普通 Ridge 的重点是让线性模型更稳定，不会自动获得复杂非线性能力。**

### 4.2 二次特征增加了什么

在原输入之外，增加：

- 温度的平方：`AT²`。
- 压力的平方：`AP²`。
- 温度与压力的乘积：`AT × AP`。

平方项可以表达弯曲，乘积项可以表达两个变量共同作用。
预测对原始输入是非线性的，但对新增特征的系数仍是线性的。

九个输入做完整二次展开、不增加常数列时，会得到 **54 个特征**。

### 优点

- 能从 CW1 的线性模型自然延伸，组员较容易掌握。
- 可以明确解释增加了哪些关系。
- 很适合分析“增加复杂度带来的性能改善是否值得”。

### 不足

- 二次项不一定足以描述所有复杂工况。
- 新增特征也可能高度相关，需要标准化和正则化。
- 超出训练工况后，平方项可能使预测快速变大；数学上能计算，不表示工程上可信。

参考：[scikit-learn Ridge 与多项式回归说明](https://scikit-learn.org/stable/modules/linear_model.html)。

### 在本项目中的位置

如果希望三个候选的方法差别更明显，**二次 Ridge 适合替换 Extra Trees**。
这是讨论建议，目前没有替换 Notebook 中的模型。

## 5. 单棵决策树：工况判断流程图

### 怎么预测

决策树逐步判断条件，例如：

```text
入口温度是否低于某个阈值？
├─ 是：继续判断排气压力
└─ 否：继续判断能量产出
```

最终到达叶节点，用落在该节点的训练记录估计 CO。
上述只是原理示意，实际判断条件和阈值由训练得到。

### 优点

- 不需要事先指定关系是直线还是曲线。
- 能表达“在某个温度范围内，再根据压力判断”的交互。
- 浅树可以画出来，适合演示和解释。

### 不足

- 树太深时，容易记住少量记录的偶然特点。
- 训练数据稍有变化，树的判断结构就可能改变。
- 预测通常呈阶梯状，未必平滑。
- 对训练范围之外的新工况，缺少可靠的外推能力。

### 主要参数

| 参数 | 通俗含义 |
|---|---|
| `max_depth` | 最多允许连续问多少层问题 |
| `min_samples_leaf` | 最终每个工况分组至少保留多少条训练记录 |

参考：[scikit-learn 决策树说明](https://scikit-learn.org/stable/modules/tree.html)。

### 在本项目中的位置

它适合教学和解释；如果只选三个主要候选，可以优先考虑更稳定的集成树模型。

## 6. 随机森林：多棵树分别估计，再取平均

### 怎么预测

单棵树可能不稳定。随机森林训练许多有所不同的树，让它们分别预测。

例如，对同一条工况记录：

| 树 | 预测 CO，纯示例 |
|---|---:|
| 第一棵 | 1.8 |
| 第二棵 | 2.2 |
| 第三棵 | 2.0 |
| 平均 | 2.0 |

这是回归，所以取数值平均。
不同的树使用随机抽样的记录，并在切分时考虑不同的候选输入，尽量避免所有树都犯一样的错误。

### 优点

- 能学习温度、压力等变量之间的非线性与交互。
- 多树平均通常比单棵树更稳定。
- 一般不需要标准化，预处理较简单。
- 参数含义比较直观，适合课程实验。

### 不足

- 大量深树可能占用较多内存，预测也需要遍历许多树。
- 完整森林难以像线性公式或浅树一样直接解释。
- 不擅长推算远离历史工况的新趋势。
- 少见的高 CO 情况可能被平均过程拉向常见水平；是否发生要检查验证尾部误差。

### 主要参数

| 参数 | 作用 |
|---|---|
| `n_estimators` | 树的数量；更多树通常增加成本，收益逐渐减小 |
| `max_depth` | 控制单棵树复杂度 |
| `min_samples_leaf` | 避免树为极少量记录建立过细规则 |
| `max_features` | 每次切分允许考虑多少输入，影响树之间的差异 |

**树多不等于一定更容易过拟合。**树深和叶节点样本数通常是更直接的复杂度控制因素。

参考：[scikit-learn RandomForestRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestRegressor.html)。

### 在本项目中的位置

建议作为主要候选之一，用来检验非线性模型能否改善后续时间段的预测。

## 7. Extra Trees：在切分时引入更多随机性

### 与随机森林有什么区别

二者都训练多棵树并取平均，但选择切分阈值的方式有所不同：

- 随机森林：在候选输入中寻找好的切分阈值。
- Extra Trees：为候选输入生成随机阈值，再从这些候选切分中选择。

scikit-learn 默认设置下，随机森林使用有放回抽样，而 Extra Trees 默认使用完整训练数据。
实验可以修改这些设置，报告应说明实际使用的参数。

### 优点

- 更强随机性可以增加树之间的差异。
- 减少寻找切分点的工作，可能降低训练成本。
- 接口和随机森林相似，组员容易交流和互相审核。

### 不足

- 随机阈值可能错过重要的精细边界。
- 不保证比随机森林更快或更准，需要实测。
- 与随机森林的原理相近，方法差异没有“树模型对比多项式模型”那么大。
- 同样存在模型体积、解释和外推限制。

参考：[scikit-learn ExtraTreesRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.ExtraTreesRegressor.html)。

### 在本项目中的位置

适合研究“更多随机性是否改善验证表现或减少成本”，是合理候选，但不是必须保留。

## 8. 直方图梯度提升：逐步修正前面的预测

### 怎么预测

随机森林中的树主要各自学习，最后平均。
梯度提升按顺序学习。以平方误差训练为例，可以这样理解：

1. 给出初步预测。
2. 检查哪些记录预测偏高、哪些偏低。
3. 下一棵树学习怎样修正这些误差。
4. 反复做小幅修正。

纯原理示例：

```text
初步预测：2.0
第一轮修正：+0.4
第二轮修正：-0.1
最终预测：2.3
```

“直方图”是一种加速方式：把连续输入分到有限数量的区间，减少寻找切分位置的计算。

### 优点

- 能逐步学习复杂的非线性规律。
- 适合在数万行表格数据上进行比较。
- 一般不需要标准化。
- 有叶节点数量、L2 正则化等复杂度控制方式。

### 不足

- 参数相互影响，调参和解释比随机森林复杂。
- 修正轮数过多、每次修正过大，可能开始追逐训练噪声。
- 极少见的高排放工况仍可能学习不好。
- 不能依靠历史数据保证新工况的泛化。

### 主要参数

| 参数 | 通俗含义 |
|---|---|
| `learning_rate` | 每轮修正迈多大一步 |
| `max_iter` | 最多修正多少轮 |
| `max_leaf_nodes` | 每棵修正树允许多复杂 |
| `l2_regularization` | 对过强的叶节点修正增加限制 |

时间验证还要注意内部早停的验证划分。目前框架关闭自动早停，让共同时间折负责验证。

参考：[梯度提升原理](https://scikit-learn.org/stable/modules/ensemble.html)、
[HistGradientBoostingRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html)。

### 在本项目中的位置

建议保留，与随机森林形成“多树平均”和“逐步修正”的清楚对照。

## 9. SVR：允许小误差，同时限制预测曲面的复杂程度

### 怎么预测

SVR 是支持向量回归。
可以想象预测曲线周围有一条容忍带：落在带内的小误差不需要努力追赶，
带外误差会受到惩罚，同时模型不能弯得太复杂。
使用 RBF 核后，可以学习非线性关系。

### 优点

- 能表达平滑的非线性。
- 可以通过正则化控制对训练数据的贴合程度。
- 与树模型原理不同，适合做方法对照。

### 不足

- 需要认真标准化，否则不同输入的尺度会影响模型。
- `C`、`gamma`、`epsilon` 相互影响，调参更费精力。
- 核 SVR 的训练成本随样本量增长较快。约 2.2 万条开发记录，再乘参数组合和五折验证，可能耗时较多。

### 主要参数

| 参数 | 通俗含义 |
|---|---|
| `C` | 多在意训练误差，相对于限制模型复杂度而言 |
| `gamma` | 一个训练记录的影响有多局部 |
| `epsilon` | 训练时允许的小误差带有多宽 |

**`epsilon=1` 不代表模型保证误差在 ±1 内。**它只是训练目标的一部分，实际覆盖率仍须评估。

参考：[scikit-learn SVR](https://scikit-learn.org/stable/modules/generated/sklearn.svm.SVR.html)。

### 在本项目中的位置

适合想深入学习核方法、愿意承担更多调参工作的组员；考虑计算和问答准备成本，不作为当前首选。

## 10. 其他可考虑模型

### KNN 回归：寻找相似历史工况

找到最接近的若干条训练记录，用它们的 CO 平均值或距离加权平均值预测。

- 优点：原理直观，能学习局部非线性。
- 不足：需要标准化；预测时要查找历史记录；高度相关输入可能重复强调同一种信息；新工况可能缺少可靠邻居。

参考：[scikit-learn 最近邻方法](https://scikit-learn.org/stable/modules/neighbors.html)。

### MLP 神经网络：通过多层计算学习复杂关系

- 优点：表达能力强，可以学习复杂变量交互。
- 不足：需要标准化；网络大小、学习率、正则化等参数较多；可能不收敛或对随机种子敏感；问答准备工作更多。

参考：[scikit-learn 神经网络说明](https://scikit-learn.org/stable/modules/neural_networks_supervised.html)。

对于本次作业，先把少数候选比较严谨，比增加更复杂模型更有价值。

## 12. 最终比较必须回答的问题

无论选择哪套模型，都用同一协议回答：

1. 对后续时间段预测得怎样？
2. 训练成绩和验证成绩的差距有多大？
3. 训练、预测和存储成本是多少？
4. 是否满足事先确定的部署约束？

平均 MAE 较低，不保证容限覆盖率较高；模型复杂，不保证预测更好。
在查看候选结果前确认主指标、约束和选择规则，不根据测试反馈改规则。
