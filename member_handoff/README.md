# Model-owner handoff

Wenyi maintains the master notebook. Each model owner edits their own experiment file.

| Member | Assigned model | Package | Instructions inside |
|---|---|---|---|
| 2 — Kiki | Random Forest Regression | `packages/GAS4_member2_starter.zip` | Chinese `交接说明.md` and English `README.md` |
| 3 | Extra Trees Regression | `packages/GAS4_member3_starter.zip` | English `README.md` |
| 4 | Histogram Gradient Boosting Regression | `packages/GAS4_member4_starter.zip` | English `README.md` |

Open the supplied personal `.ipynb` in Jupyter or Colab. Follow the instructions inside your package. Write analysis in its existing text cell, save outputs, and return the edited notebook and results ZIP. The `.py` file is an alternative entry; use one as your working file.

Keep the common module, data, split and scoring unchanged. If the numerical protocol changes, Wenyi distributes the update and all affected experiments are rerun. Member 5 benchmarks all candidates on one runtime and evaluates the final fixed pipeline once.

The package builder may overwrite starters: do not run it over a member's edited notebook. The course submission is one integrated notebook, not three personal starters.
